\chapter{The Injection Engine}

\section{Motivation}

AnyLogic projects are stored as structured XML artifacts. Manual GUI-based edits to inject custom logic, models, or UI code are time-consuming and difficult to reproduce. To support repeatable experiments, Aegis-IoT includes an automated injection workflow that applies deterministic transformations to the project file.

\section{What Gets Injected}

The injection workflow supports three categories of updates:
\begin{itemize}
    \item \textbf{Intelligence components:} integration points for predictors, anomaly scoring, forecasting, and control logic.
    \item \textbf{Visualization:} desktop dashboard classes and startup initialization.
    \item \textbf{Simulation tuning:} parameter adjustments for queue capacities and delay expressions.
\end{itemize}

\section{Reproducibility}

Treating the simulation enhancement as a scripted transformation makes experiments auditable and repeatable. Given a clean base model, the same injection sequence produces a consistent, fully instrumented AnyLogic project suitable for evaluation and demonstration.
