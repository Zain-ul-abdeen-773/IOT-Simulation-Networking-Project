\section{Simulation Model}

The simulation is implemented in AnyLogic \cite{anylogic} using an agent-based discrete-event approach. Table~\ref{tab:agents} lists the principal agent types.

\begin{table}[H]
\centering

\label{tab:agents}
\begin{tabularx}{\textwidth}{@{}lXl@{}}
\toprule
\textbf{Agent} & \textbf{Role} & \textbf{Count} \\
\midrule
SensorDevice & Generates telemetry packets using dataset-derived distributions & Multiple \\
MQTTPacket & Carries network metrics through the simulated path & Dynamic \\
Main & Orchestrates execution and hosts the intelligence pipeline & 1 \\
\bottomrule
\end{tabularx}
\end{table}

Each packet carries a small set of features used for analytics and visualization (Table~\ref{tab:mqttfields}).

\end{table}

\section{Processing Pipeline}

When packets reach the cloud sink, the simulation executes a fixed sequence:
\begin{enumerate}
    \item optional stress-traffic injection to emulate attack-like outliers,
    \item congestion-aware control decision via the RL policy,
    \item feature preparation and model inference (prediction, anomaly scoring, forecasting), and
    \item broadcast of updated telemetry to the visualization layers.
\end{enumerate}
