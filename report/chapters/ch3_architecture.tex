\section{Simulation Model}

The simulation is implemented in AnyLogic \cite{anylogic} using an agent-based discrete-event approach. Table~\ref{tab:agents} lists the principal agent types. Note that unlike a traditional multi-tier network, the AnyLogic model concentrates intelligence within the \texttt{Main} agent; gateway and cloud routing logic is embedded in the packet-processing hooks injected by the Injection Engine rather than modeled as separate agent classes.

\begin{table}[H]
\centering
\caption{AnyLogic Agent Types}
\label{tab:agents}
\begin{tabularx}{\textwidth}{@{}lXl@{}}
\toprule
\textbf{Agent} & \textbf{Role} & \textbf{Count} \\
\midrule
SensorDevice & Generates telemetry packets using dataset-derived distributions & Multiple \\
MQTTPacket & Carries network metrics (\texttt{packetSize}, \texttt{interArrival}, \texttt{flowDuration}) through the simulated path & Dynamic \\
Main & Orchestrates execution: hosts all four transpiled models, the RL controller, GAN-style stress injection, dashboard windows, and telemetry export & 1 \\
\bottomrule
\end{tabularx}
\end{table}

\section{Processing Pipeline}

When packets reach the processing sink inside \texttt{Main}, the simulation executes the following sequence:
\begin{enumerate}
    \item \textbf{GAN-style stress injection:} with 5\% probability, the packet's features are mutated to emulate volumetric DDoS traffic (large packet size, micro-burst inter-arrival, inflated flow duration). This synthetic adversarial perturbation validates the anomaly detector under attack-like conditions.
    \item \textbf{RL congestion control:} the \texttt{QTableBalancer} maps the current queue proxy to a discrete state, selects an action (accelerate $0.5\times$, maintain $1.0\times$, or throttle $2.0\times$) via $\epsilon$-greedy policy, applies the multiplier to \texttt{flow\_duration}, and updates the Q-table using the temporal-difference rule.
    \item \textbf{Model inference:}
    \begin{itemize}
        \item \texttt{OfflineAiPredictor.score()} estimates latency from \texttt{(packetSize, interArrival)}.
        \item \texttt{AnomalyModel.score()} computes a novelty score from \texttt{(packetSize, interArrival, flowDuration)}.
        \item \texttt{FutureForecaster.score()} predicts latency 10 steps ahead using a BiLSTM-based sliding window over recent flow durations.
    \end{itemize}
    \item \textbf{Telemetry broadcast:} updated metrics are pushed to the five NOC dashboard windows and, on export, written as a JSON artifact consumed by the web dashboard.
\end{enumerate}
