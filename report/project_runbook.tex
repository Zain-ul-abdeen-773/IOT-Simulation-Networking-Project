\section*{Introduction to the Pipeline}
This runbook provides complete, detailed instructions for compiling, deploying, and validating the Aegis-IoT environment completely within the AnyLogic engine. Our entire system operates directly out of the Java-based AnyLogic instance and Python logic—removing any external web dependencies.

Aegis-IoT relies on four main pillars: Data/ML preparation (Python), Code Injection (Python), the Core Simulation Engine (AnyLogic JVM), and Native Visualization Interfaces (Java Swing).

\section{Step 1: Check System Prerequisites}

To run this stack natively, you need local installations of specific tools. Ensure the following are available on your system path. Open a terminal (PowerShell, Command Prompt, or VS Code terminal) and verify:

\begin{terminalBox}[(Checking Versions)]
python --version
java -version
\end{terminalBox}

\begin{itemize}[leftmargin=*]
    \item \textbf{Python (3.8+):} Required for training the Machine Learning models (Scikit-Learn), running the XML mutation scripts, and executing the Federated Learning scenarios.
    \item \textbf{Java JDK (11+):} Required by the AnyLogic engine to compile and run the generated bytecode and custom Swing dashboards.
    \item \textbf{AnyLogic 8.x:} You must have the AnyLogic IDE installed to actually open, compile, and run the \texttt{.alpx} modeling file natively.
\end{itemize}

\section{Step 2: Install Project Dependencies}

We now need to install the external Python libraries required for our AI agents. Ensure your terminal is in the root directory (\texttt{FinalCCNProject}), then run:

\begin{terminalBox}[(Python Packages)]
pip install -r requirements.txt
\end{terminalBox}

This installs \texttt{scikit-learn} (for Random Forest/OneClassSVM), \texttt{m2cgen} (for converting ML models to native Java code), and \texttt{pandas/numpy} for data wrangling. Keep your \texttt{requirements.txt} current for any future ML additions.

\section{Step 3: Synthesize ML Models into Java (M2CGen)}

A core feature of Aegis-IoT is zero-latency inference directly inside AnyLogic. We train our machine learning models in Python and use the \texttt{m2cgen} library to transpile them straight into pure Java bytecode.

Navigate to the \texttt{model} directory and execute the training pipelines:

\begin{terminalBox}[(ML Transpilation)]
cd model
python train\_latency\_random\_forest.py
python test\_m2cgen4.py
cd ..
\end{terminalBox}

\textbf{What exactly did this do?}
\begin{itemize}
    \item \texttt{train\_latency\_random\_forest.py} trained a Voting Regressor ensemble to predict packet latency based on packet sizes, inter-arrival times, and gateway queuing. It exported this directly into \texttt{OfflineAiPredictor.java}.
    \item \texttt{test\_m2cgen4.py} trained a OneClassSVM model on normal traffic patterns to act as an Anomaly Radar (detecting DDoS bursts). It appended this logic to the same Java file.
    \item These intelligent models are now hardcoded natively into the Java source files, meaning AnyLogic does not need an API to perform AI inference!
\end{itemize}

\section{Step 4: Inject UI and RL Features into the AnyLogic Core}

To avoid endless manual GUI work in the AnyLogic editor, Aegis-IoT uses Python scripts to perform surgical XML injection into the AnyLogic project files. 

Run the following commands from the root directory:

To guarantee the model has all final improvements completely applied (including the new BiLSTM tweaks), you must run the entire injection sequence chronologically:

\begin{terminalBox}[(XML Mutation Engine)]
cd injection\_scripts
python inject\_multi\_dashboard.py
python inject\_rl\_and\_gan.py
python inject\_v2\_upgrades.py
python inject\_v3\_fixes.py
python inject\_v4\_final.py
python inject\_v5\_safe\_tweaks.py
python inject\_v6\_bilstm\_tweak.py
cd ..
\end{terminalBox}

\textbf{What exactly did this do?}
\begin{itemize}
    \item \texttt{inject\_multi\_dashboard.py}: Modified the AnyLogic startup sequence to automatically spawn four independent \textbf{Java Swing windows} when the simulation starts.
    \item \texttt{inject\_rl\_and\_gan.py}: Hooked the Tabular Q-Learning agent (\texttt{QTableBalancer.java}) into the Gateway objects.
    \item \texttt{inject\_v2}-\texttt{v6}: Sequentially apply all the final model stability fixes up to the new BiLSTM tweak directly into the XML structure.
\end{itemize}

\section{Step 5: Launch the Core AnyLogic Simulation}

It is time to bring the system online and prove self-contained execution. 

\begin{enumerate}[leftmargin=*]
    \item Open the \textbf{AnyLogic} desktop application.
    \item Go to \textbf{File > Open} and navigate to \texttt{Anylogic Models/FinalCCNProject1}.
    \item Select \texttt{FinalCCNProject1.alpx} (or \texttt{.alp}).
    \item Once loaded, look at the Project explorer panel on the left. Find the \textbf{Main} experiment.
    \item Right-click the Main experiment and select \textbf{Run} (or click the green Play button on the toolbar).
\end{enumerate}

\begin{infoBox}
\textbf{Expected Native Behavior:} 
A Simulation window will open. As configured by our injection scripts, \textbf{four custom Java Swing dashboards} will also pop up on your screen. The \texttt{SensorDevice} agents will begin generating MQTT packets, and you will see the \texttt{Gateway} agents actively routing them. The central database (\texttt{RUNTIME\_LOGS}) will instantly start populating with native intelligence logs.
\end{infoBox}

\section{Step 6: Run the Federated Learning Scenario}

Aegis-IoT includes a decentralized intelligence suite demonstrating FedAvg (Federated Averaging). This runs independently alongside the simulation to prove privacy-preserving edge training without relying on web services.

You will need to run the cloud aggregator and the edge nodes concurrently.

\textbf{1. Start the Cloud Server} (Open a new terminal):
\begin{terminalBox}[(Federated Server)]
cd federated
python cloud\_server.py
\end{terminalBox}
\textit{This server awaits connections from multiple edge nodes to combine their trained weights locally.}

\textbf{2. Start an Edge Node} (Open another new terminal):
\begin{terminalBox}[(Edge Node)]
cd federated
python edge\_node.py
\end{terminalBox}
\textit{The edge node trains an SGDRegressor strictly on local (simulated) data partitions. It transmits ONLY the weights mathematically back to the cloud server.}

\textbf{3. View the Results}:
Once the communication rounds complete, visualize the training convergence:
\begin{terminalBox}[(Plot Output)]
python plot\_federated.py
\end{terminalBox}
This outputs Matplotlib graphs demonstrating how the decentralized models converged efficiently.

\section{Final Validation}

If you have followed all steps, your environment should now represent a fully functioning Aegis-IoT ecosystem completely centered around AnyLogic:
\begin{enumerate}
    \item The AnyLogic simulator is visibly processing intelligent decision boundaries.
    \item The transpiled M2CGen Java files are driving zero-latency logic with no backend web APIs.
    \item The Java Swing GUI displays active radar, telemetry, and Q-Learning output directly from the JVM.
    \item Complete logs are captured securely in local SQL databases.
\end{enumerate}
